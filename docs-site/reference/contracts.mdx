## Maren contracts

<Warning>
  **Maren is deployed to Mezo matsnet (chain `31611`) only.** Its mainnet addresses are all
  zeroes because Maren is not on mainnet: a third-party audit is the deliberate gate. The
  deployment block floor for matsnet is `14,911,471`; on mainnet it is `null`, meaning there is
  no history to read.
</Warning>

</Note>

implementation address. All fifteen addresses were verified three independent ways: the

## Precompiles and standard infrastructure

Two things a developer reaches for on other chains behave differently here. The BTC/USD oracle is
a native chain precompile, not a deployed Chainlink or Pyth contract, and the ERC-4337 EntryPoint
is deployed but inert.

| Component | Address | Status |
| --- | --- | --- |
| BTC gas-token precompile | `0x7b7C000000000000000000000000000000000000` | Live |
| Price oracle precompile | `0x7b7c000000000000000000000000000000000015` | Live, Skip Connect |
| MEZO token precompile | `0x7B7c000000000000000000000000000000000001` | Live |
| Multicall3 | `0xcA11bde05977b3631167028862bE2a173976CA11` | Deployed both networks |
| Permit2 | `0x000000000022D473030F116dDEE9F6B43aC78BA3` | Deployed |
| x402 settlement proxy | `0x402085c248EeA27D92E8b30b2C58ed07f9E20001` | Live both networks |
| ERC-4337 EntryPoint v0.7 | `0x0000000071727De22E5E9d8BAf0edAc6f37da032` | Deployed and inert |

<Warning>
  The price oracle precompile implements only `decimals()` and `latestRoundData()` from the
  Chainlink `AggregatorV3` interface; `description()` reverts. It reverts entirely above 60
  seconds of staleness. Pyth is also deployed on Mezo but its feeds run roughly 28 days stale and
  ETH/USD reverts outright, so it is not a usable substitute. Maren reads the precompile, the same
  source MUSD's own liquidation engine uses. See [Networks](/reference/networks).
</Warning>

<Warning>
  The ERC-4337 EntryPoint has processed zero UserOperations and no compliant bundler can run
  against Mezo, because the RPCs lack `debug_traceCall`. It is recorded here only so nobody
  rediscovers it and concludes 4337 is viable. It is not. See [Gasless](/how-it-works/gasless).
</Warning>
